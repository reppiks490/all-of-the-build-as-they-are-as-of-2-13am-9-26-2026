THE TRUTH PROTOCOL

Beauty cannot certify truth.

A genuine world engine needs to keep observations, assumptions and unverified outputs separated. That boundary is a core feature, not a disclaimer hidden in the footer.

01 / OBSERVED

Traceable reality

Timestamped data, independent sources, publication vintages, revisions, licenses, and exact code versions. A real connector must show when it last succeeded.

02 / MODELLED

Transparent assumptions

Every causal edge has an owner, coefficient, competing interpretation, sensitivity range, and validation method. Simulated paths never masquerade as observations.

03 / UNVERIFIED

Falsifiable futures

Out-of-sample failures, alternative explanations, parameter instability and calibration gaps remain visible. Permissioned actions require separate approval.
