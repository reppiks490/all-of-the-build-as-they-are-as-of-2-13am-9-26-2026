# EPOCH Ω — The Ambition Map (future work, not shipped)

The ambition is to move from a spectacular scenario viewer to an **evidence-licensed, interventionally credible, motion-rich decision research platform**. Each milestone is independently testable. Feature counts and agent counts are not proxies for validity.

## Level A — Reality ingestion and the time machine

| ID | Deliverable | Proof required |
| --- | --- | --- |
| A01 | Provider adapter SDK for FMP, TickerLayer, CoinGecko, Massive and approved alternatives | Schema tests for identity, units, timestamps, rights and disconnects |
| A02 | Bitemporal event store with append-only revisions | As-known-at replay unaffected by later corrections |
| A03 | Economic release-vintage ingestion (e.g. ALFRED) | No pre-publication feature availability in a frozen historical test |
| A04 | Content-addressed provenance graph linking paper, claim, indicator, run and visualization | Trace any displayed outcome back to exact inputs and code |
| A05 | Multi-provider conflict mediation, with rank and methodology explanations | Disagreement is shown, never silently averaged across incompatible quotes |
| A06 | License-aware purpose and export policy | Undocumented and restricted inputs are blocked at ingestion/export |

## Operating constraints

Do not integrate all tools merely because they are named. Use the smallest bounded connector set that solves a defined problem. Models built from synthetic behavior are not empirical digital twins, and generated visual coherence cannot serve as proof of physical or economic fidelity. Research licensing, GPU costs and cloud spend must be explicitly approved where necessary. No scheduled Codex loop or background autonomous trading is authorized by this roadmap.
